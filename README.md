# Section 9 Dotfiles

Ghost in the Shell-inspired Hyprland desktop configuration for Arch Linux, based on ArchEclipse.

## Features

- Hyprland desktop environment
- AGS bar, panels, launcher, and notifications
- Quickshell Matrix rain and scan-line desktop effects
- Section 9 SDDM login theme
- Kitty, Zsh, Starship, Fastfetch, and Neovim configuration
- Modern shell tools including `eza`, `bat`, `fd`, `fzf`, `zoxide`, and `ripgrep`
- Automated package installation and configuration linking
- `section9-doctor` environment validation

## Installation

```bash
git clone git@github.com:GodHVoid/section9-dotfiles.git ~/Git/section9-dotfiles
cd ~/Git/section9-dotfiles
./install.sh remote-laptop
```
